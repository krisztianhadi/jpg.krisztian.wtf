Conventions used across these docs:

- Copy rule: a plain `-` is used, never an em dash.
- Changelog entries are dated and tagged `[Feature]`, `[Fix]`, `[Break]`,
  `[Tweak]` or `[Docs]`.
- The review and the task list share ids: an `R-nn` finding is fixed by the
  `T-nn` tasks that reference it.
