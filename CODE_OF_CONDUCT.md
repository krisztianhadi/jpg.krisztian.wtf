# Code of conduct

Be decent. Concretely, in issues, pull requests and discussions:

- critique code and ideas, never people;
- assume the other person is acting in good faith and ask before assuming intent;
- no harassment, slurs, personal attacks, or unwelcome sexual attention;
- keep it on topic - this is a small tool for showing photographs.

Maintainers may edit, lock or remove comments and contributions that break
these rules, and may block accounts for repeated or serious violations.

Report a problem privately to the maintainer (see [SECURITY.md](SECURITY.md) for
the contact channel) rather than escalating in public.

This is a deliberately short version of the Contributor Covenant; the full text
is available at https://www.contributor-covenant.org/version/2/1/code_of_conduct/
if you want the long form.
